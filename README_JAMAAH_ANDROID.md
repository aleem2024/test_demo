# Jamaah Reminder Android

September 2026 Android reminder app.

- All five daily prayers use the September 2026 timetable configured in `ReminderScheduler.kt`.
- Friday Dhuhr is replaced by four-mosque / ten-Jamaat Jumu'ah reminders.
- Daily reminders: 15, 10, 5 and 0 minutes before Jama'ah.
- Jumu'ah reminders: 20 minutes before each unique Jamaat time, grouping mosques that share the same time.
- GitHub Actions workflow builds a debug APK artifact.
